# Kazamachi

A photo-friendly breeze-to-storm wind system for VRChat avatars. Kazamachi animates PhysBone roots through looping FX Animator clips generated at build time.

## Install and quick start

Add the VPM repository `https://tenteeeee.github.io/vpm-repos/index.json`, install **Kazamachi**, select an avatar root, then choose `GameObject > Kazamachi`. Adjust the component and build through NDMF. Use the `Kazamachi` Expression Menu: **Wind** toggles the effect, and **Direction**, **Strength**, **Turbulence**, and optional **Elevation** adjust it at runtime.

Requires Unity 2022.3, VRChat Avatars SDK 3.10.5+, and NDMF 1.14.8+. Read the [Japanese project overview](README.ja.md) and [Japanese package user manual](Packages/com.tentee.vrc-kazamachi/README.md).
